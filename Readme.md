# Проект «Седона»

## Техническое задание
### 1. Общие технические требования
1.1. Стандарты вёрстки: HTML, CSS, прогрессивное улучшение.
1.2. Сетка: определена в макете.
1.3. Адаптивность вёрстки: нет.
1.4. Используемые фреймворки: нет.
1.5. Кроссбраузерность: Chrome, Firefox, Safari.
1.6. Типографика: определена в макете.
1.7. Используемый шрифт: PT Sans. Шрифт есть в папке проекта и на Google Fonts.
1.8. С макетом предоставлен стайлгайд, содержащий прорисовку состояний элементов интерфейса. При любых расхождениях с макетами он должен иметь наивысший приоритет.
### 2. Пояснения для учащихся
2.1. Обязательными к вёрстке являются 2 страницы (главная страница, страница каталога).
### 3. Обязательные требования
Все макеты
3.1. Контентная область центрируется и не может быть уже макетной ширины.
3.2. Логотип является ссылкой, которая ведёт на главную страницу на любых страницах.
3.3. Слева и справа от контентной области есть серый фон, который бросает лёгкую тень на сайт.
3.4. Логотип Академии в подвале ведёт на лендинг интенсива «HTML и CSS. Профессиональная вёрстка сайтов».
Главная
3.5. Шапка: число «12» в избранном может быть изменено на любое двухзначное число. При клике на иконку сердца происходит переход на страницу избранного. Реализовывать страницу не нужно.
3.6. Шапка: при клике на лупу происходит переход на страницу поиска. Реализовывать страницу не нужно.
3.7. Шапка: при взаимодействии с элементом «Хочу сюда!» происходит переход на другую страницу. Реализовывать страницу не нужно.
3.8. Крупное фото: фотография занимает всю ширину блока, в её нижней части есть белая маска.
3.9. Hero-блок: Надпись «Welcome to the gorgeous Sedona, because the Grand Canyon sucks!» является контентным изображением. Текст переводить не нужно.
3.10. Блок «жильё», «еда», «сувениры»: иконки являются декоративными изображениями.
3.11. Блок «Заинтересовались?»: кнопка «Поиск гостиницы в седоне» открывает модальное окно.
3.12. Блок «подпишитесь на рассылку»: форма не должна отправляться если поле пустое. «Подписаться» отвечает за отправку формы на адрес https://echo.htmlacademy.ru/.
3.13. Подвал: при клике на номер телефона можно позвонить.
Каталог
3.14. Ссылка «Гостиницы» является текущей и не ведёт сама на себя.
3.15. Хлебные крошки: иконка домика ведёт на главную страницу.
3.16. Фильтр: верстать с помощью формы, кнопка «Применить» отвечает за отправку формы на адрес https://echo.htmlacademy.ru/.
3.17. Фильтр: кнопка «Сбросить» возвращает форму в изначальное состояние.
3.18. Фильтр: элементы рендж-слайдера для изменения полей «от» и «до» являются интерактивными.
3.19. Сортировка: элементы смены вида являются ссылками с get-параметрами.
catalog.html?view=tile
catalog.html?view=card
catalog.html?view=list
3.20. Карточка товара: кнопка «В избранное» добавляет в избранное, а «В избранном» удаляет из избранного. Реализовывать смену состояния не нужно.
3.21. Карточка товара: «Подробнее» переводит на подробную страницу отеля. Реализовывать страницу не нужно.
3.22. Пагинация: с активным элементом нельзя взаимодействовать, поэтому у элемента не должно быть состояний :hover, :focus, :active.

## 2.44. Разметка всех страниц

В форке вашего проекта выполните разметку страниц в файлах index.html и catalog.html (создать этот файл при необходимости)
Нужен только HTML-код, стили делать не нужно.
На этом этапе не нужно размечать содержимое всплывающих окон и выпадающих блоков.
Также не нужно указывать пути и размеры для изображений. Достаточно разметки такого вида — <img src="#" alt="Описание картинки">.
Для скрытых элементов используйте класс class="visually-hidden".
Если страница существует в макете, то на неё должна вести соответствующая ссылка, например, <a href="catalog.html">.
Если страницы нет в макете, то ссылка на неё должна быть следующего вида — <a href="#"></a>.
Для тестирования правильности работы форм можно использовать адрес https://echo.htmlacademy.ru/.

## 5.22. Сетка страниц и крупных блоков на флексах

В форке вашего проекта создайте сетку страниц и крупных блоков страниц.

Расположите элементы страниц по сетке.
Стики футер: min-height, height для <html> и <body>.
Крупные блоки и блоки, количество которых не изменяется.
Используйте свойства: flex, flex-grow, justify-content.
Горизонтальные размеры и отступы: width, max-width, margin, padding.
Для удобства можно использовать способ визуального выделения элементов с помощью свойства outline (для удобства также можно использовать разные цвета). Использовать свойство border в качестве такого визуального выделения не стоит, так как border будет влиять на ширину блока при использовании свойства (по умолчанию, для всех элементов на страницах задано box-sizing: content-box).
